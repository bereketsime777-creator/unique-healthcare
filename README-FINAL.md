## 🎓 How to Use

### For Switching Language
1. Look for 🌐 button in top-right navbar
2. Click button
3. Choose English or አማርኛ
4. Entire site updates instantly
5. Preference saved for next visit

### For Managing Categories (Admin)
1. Login as admin
2. Click Admin Dashboard
3. Click "Manage Categories" 
4. Click "Add New Category"
5. Fill form and submit
6. Category appears everywhere

### For Filtering Products (Users)
1. Go to Products page or Home
2. Look for category filter/banners
3. Click a category
4. Products filter in real-time
5. See only that category's products
