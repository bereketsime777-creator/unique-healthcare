📊 HOW IT WORKS:

1. User visits: /products/mindray-analyzer
2. ProductDetails component loads
3. useMetaTags hook triggers
4. Hook updates document.head with product data
5. Social crawler visits URL
6. Crawler reads updated meta tags
7. Social preview shows:
   - Product image ✅
   - Product name ✅
   - Product description ✅
   - Unique Healthcare branding ✅
